bel-ai-jar

Git hooks for understanding AI-generated code changes

The Problem

AI agents are increasingly co-authoring code

Developers often commit AI-generated code without fully understanding it

This creates technical debt and knowledge gaps in teams

Current tools don't help developers learn from AI-generated changes

Our Solution

bel-ai-jar is a Git hooks library that:

  • • Analyzes AI-generated code changes before commit
  • • Generates questions about the implementation
  • • Requires developers to answer questions correctly
  • • Ensures understanding before allowing commits

Key Features

AI-Powered Questions

Generates relevant questions about code changes using Mistral AI

Configurable Evaluation

Set number of questions, answer options, and passing grade

Git Hooks Integration

Seamlessly integrates with your Git workflow

Multiple AI Models

Supports Mistral, OpenAI, and local Llama instances

Strict Mode

Require 100% correct answers or set custom passing grades

Prompt Customization

Add custom prompts to enhance question generation
